# 设计系统

GeekGeekRun 采用统一的**浅色主题**，基于 Element Plus 定制。所有渲染窗口与 `body` 弹出的浮层共用同一套语义色。

## 色彩规范

### 主色

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--el-color-primary` | `#1668dc` | 主色（按钮、链接、选中态） |
| `--ggr-primary-hover` | `#175cd3` | 主色悬浮态 |
| `--el-color-primary-dark-2` | `#154eaf` | 主色按下态 |

### 语义色

| 变量 | 值 | 含义 |
| --- | --- | --- |
| success | `#287a1d` | 成功 |
| warning | `#96620a` | 警告 |
| danger / error | `#b42318` | 危险、删除、覆盖 |
| info | `#667085` | 信息、次要文字 |

其中「危险 / 删除 / 覆盖」统一使用红色 `#b42318`，例如删除记录、覆盖数据的确认按钮。

### 文字色

| 变量 | 值 |
| --- | --- |
| primary | `#26373b` |
| regular | `#475467` |
| secondary | `#667085` |
| placeholder | `#6b7280` |
| disabled | `#98a2b3` |
| brand text | `#17665f`（品牌强调文字，青绿色） |

## 设置与任务配置的文字层级

| 角色 | 字号 | 字重 |
| --- | --- | --- |
| 页面标题 | 24px | 700 |
| 分区标题 | 18px | 700 |
| 字段、分组与控件 | 14px | 400—600 |
| 辅助信息 | 12px | 400 |

字号使用 `app-theme.css` 的 `--ggr-font-size-*` 变量。新组件不再单独覆盖同类标题字号。机制说明按需查看，当前错误、额度用尽及待核对状态保持可见。风险选择使用简短红色提示，不套用表示操作失败的大块错误样式。

## 桌面主工作区

主工作区采用扁平化设计：低饱和灰绿纯色底、白色内容面板、细边框和小圆角，不使用渐变、玻璃折射或装饰阴影。青绿色用于品牌与导航选中态；主要操作和状态仍沿用 Element Plus 语义色。页面标题下方常驻一行简短用途说明，详细机制保留在帮助提示中。

- 找岗位以步骤、配置分组和固定操作栏组织内容；消息跟进按配置分组展示，运行状态保持可见。
- 求职记录、资料库和任务列表以筛选工具栏、表格和状态为中心；设置按功能分组展示。
- 表格区分初次无数据、筛选无结果、加载中和读取失败；筛选无结果提供清除筛选，读取失败保留错误详情与重试入口。
- 找岗位和消息跟进在未登录、登录失效或访问受限时显示原因及处理入口；找岗位展开配置侧栏后由侧栏承载同一状态，正常登录不重复显示醒目提示。
- 窄窗口保留导航折叠、表单换行与内容滚动；键盘焦点、危险确认和错误提示沿用全局规范。
- 主界面的布局、内容和弹层样式分别位于 `workspace-shell.css`、`workspace-content.css` 和 `workspace-overlays.css`，不覆盖独立助手窗口。
- 主界面通知同样使用纯色、细边框和小圆角；关闭按钮常驻，支持键盘聚焦与关闭。
- 消息跟进的“处理时间”独立分组，默认启用周一至周五 09:00–18:00；开关、工作日和起止时间使用明确标签，错误紧邻对应字段。按电脑本地时间判断，结束早于开始表示次日结束，工作日归属开始当天。
- 工作时间外显示“等待工作时间”及下次检查时间；保持应用运行会自动继续，其他排队任务可先运行。开始前确认和任务配置记录包含处理时间；发送前再次检查时段，到点后放弃未发送内容，下次重新检查会话。
- “设置 → AI 与简历”集中提供 PDF / Markdown 导入、简历正文核对与修改、最低匹配分数及求职方向。文件解析在本机进行；保存和调用 AI 的状态分别展示，解析或模型错误保持可见。
- 启用 AI 匹配时，找岗位页面说明 AI 判断与明确条件的分工，暂时隐藏岗位名称、分类和描述关键词控件；筛选预览对通过明确条件的岗位显示“待 AI 判断”。开始前确认包含分数阈值。
- 已保存详情展示 AI 分数、通过状态、判断依据、优势、差距、模型和分析时间；历史结果与当前简历或匹配配置不一致时提示重新分析。低分略过不等于在平台标记“不合适”。
- 全量配置迁移位于“设置 → 数据管理”。密钥与登录凭证分别显式选择，导入确认展示覆盖内容，覆盖按钮使用危险色；只有写入成功后重新载入。错误不得伪装为导入成功。

## 按钮状态

填充按钮的悬浮 / 按下态保持深色以保证白字可读：

- 主色：悬浮 `#175cd3`，按下 `#154eaf`；
- 成功 / 警告 / 危险 / 信息：悬浮与按下统一使用各自 `dark-2` 变体（如危险按下 `#912018`）。

`.ggr-danger-confirm` 为危险确认按钮类：红色背景白字，悬浮 / 按下更深，用于删除、覆盖等不可逆操作。

## 焦点与无障碍

- 键盘焦点：`focus-visible` 时显示 `2px` 主色描边，`outline-offset: 3px`；禁用按钮描边为禁用文字色；
- 强制颜色模式（`forced-colors: active`）下，焦点描边切换为系统 `Highlight` 色，保证高对比度环境可用。

## 侧边栏与窗口材质

左侧导航使用不透明纯色面板，选中项以色块和青绿色侧边线标识；折叠时以描边标识选中项。主工作区不再渲染玻璃滤镜和动态反光。窗口原生材质配置保持跨平台兼容，但不影响工作区的不透明外观。
